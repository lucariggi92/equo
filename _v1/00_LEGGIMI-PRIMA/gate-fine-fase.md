# Gate di fine fase

> Checklist riusabile. Applicala alla **fine di ogni fase** prima di passare alla
> successiva. Se anche una sola casella resta vuota, la fase non e' chiusa.

## Gate generico (vale per ogni fase)

- [ ] **Output prodotto** — l'artefatto previsto dalla fase esiste ed e' completo.
- [ ] **`Agent.md` aggiornato** — riflette lo stato e le decisioni di questa fase.
- [ ] **`workspace.md` accodato** — c'e' un blocco con i prompt usati e le decisioni.
- [ ] **Coerenza con MVP0** — niente di nuovo contraddice l'MVP0 e i no-goal.
- [ ] **Niente scope creep** — non ho aggiunto feature/schermate/asset fuori scope.
- [ ] **Input per la prossima fase pronto** — la fase successiva ha cio' che le serve.

## Nota di passaggio

Prima di procedere, scrivi una riga: cosa passa alla fase successiva.
> (compila)

## Promemoria per fase

| Fase | Output che deve esistere |
| --- | --- |
| 1 Scoping | `Agent.md` v1, `workspace.md`, scheda-scoping |
| 2 MVP0 | MVP0 (1 frase), no-goal vs post-MVP, flusso discorsivo |
| 3 Paper prototype | mappa schermate + scheda per schermata (scopo/azione/asset) |
| 4 Wireframe | un wireframe per schermata (solo essenza) |
| 5 Asset | asset generati + registro asset |
| 6a Design system | `DESIGN.md` (hex, tipografia, componenti+stati) |
| 6b Layout | layout per schermata (redesign vero, coerenti) |
| 7 Mockup/Handoff | screenshot finali + documento di handoff |
